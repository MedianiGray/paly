接下来做什么

每条先定名字、再定它只做的那件事，最后才写代码。按阻力最小排：先做不依赖策略、当天能收尾的。

  • 打砖块反弹球，把砖消完已上线
  • 反应测试测一次点击有多快已上线
  • 躲避躲开下落的障碍，活得越久越好已上线
  • 扫雷靠数字推理排雷已上线
  • 打字冲刺统计一分钟打对多少字已上线
  • 井字棋三连线，对手是机器已上线
  • 像素画板涂像素，没有输赢计划中

一律不做：账号、云端排行榜、皮肤商城、签到、成就、联机。想加其中任何一样，就另开一个项目，让它自己有准确的名字。

这里的规矩：名字即承诺

一个项目只做一件事——名字说什么，就只做什么。贪吃蛇只管吃和躲，2048 只管合数字，翻牌只管配对，打砖块只管消砖，反应测试只负责计时，躲避只管躲，扫雷只管推理，打字冲刺只数打对的字，井字棋只管轮流连三，谁都不兼职。招牌上的 GODLIKE、INVINCIBLE、PRO MAX 承诺的是强度：开场有仪式、每次操作都有反馈、结束给评级、有声音、有前五榜。九个项目现在全部按这套做完了。位置还空着，会陆续往里加；加新项目的流程写在仓库 README 里。
